# Quickstart: Validating Book Reviews

**Feature**: `specs/010-books/spec.md` | Contract: [contracts/http.md](./contracts/http.md) | Model: [data-model.md](./data-model.md)

## Prerequisites

- Go 1.24 (`go version`), no other toolchain — no Node, no external services
  (Principle I: the whole feature exercises through `go test`).

## Automated validation (primary, CI-grade)

```sh
go build ./... && go vet ./... && go test ./...
```

Expected: all packages `ok`. The feature-specific suites prove each success criterion
against fixture data directories built with `t.TempDir()` (a nested layout mirroring
the real vault: series sub-folder, `Books.md` index note, a coverless book, a
malformed-frontmatter note):

| Suite | Demonstrates |
| --- | --- |
| `internal/braind/books` `TestParseNote*` | Field normalization and leniency rules (data-model.md tables), incl. `4.5/5`, date coercion, unsafe cover names. |
| `…books TestCatalogScan*` | Recursive scan finds all fixture books exactly once; index/Waypoint notes excluded; malformed note skipped and counted, others still listed (FR-003/FR-011, SC-001); sort order newest-first, undated last, then title (FR-006). |
| `…books TestCreateReview*` | Generated bytes match the serialization contract byte-for-byte; `O_EXCL` no-overwrite via `-2` suffix; oversize/unsafe-input refusals write nothing (FR-008/FR-010, SC-002). |
| `internal/braind/books_test.go` (httptest) | Route contract: anonymous → login redirect, viewer POST → 403, bad CSRF → 403, read-only → 403 + no form, cover traversal (`..`, encoded slashes) → 404, success → 303 and the new note appears on the next `GET /books` (SC-004, FR-009/FR-012). |
| `internal/braind/books_write_test.go` (httptest) | Edit form prefill, role and CSRF gates, in-place update, and shelf refresh; no duplicate note is created (FR-013–FR-018, SC-005/SC-006). |

## Local manual pass (optional)

```sh
mkdir -p "/tmp/braind-data/01 - Note Box/Hobby/Books" "/tmp/braind-data/06 - Meta/Attachments"
cp -r tmp/Books/. "/tmp/braind-data/01 - Note Box/Hobby/Books/"   # 130-book real sample (gitignored)
cp /some/cover.jpg "/tmp/braind-data/06 - Meta/Attachments/"
go run ./cmd/braind   # with BRAIND_DATA_PATH=/tmp/braind-data and normal OIDC env
```

Expected: landing page shows the Books card; `/books` lists 130 entries newest-first
with readable covers resolving from the attachments folder and the bundled fallback
cover for absent or unusable attachments; submitting the form creates one `.md` file
in the Books folder root that opens in Obsidian with frontmatter intact. Editing a
nested entry updates that same file and leaves unrelated frontmatter intact.

test artifact. Anonymous `curl -i …/books` → `302` to `/login`; `GET /books/covers/..%2F…`
→ `404`.
