# Keep Obsidian Headless artifacts private

**Status**: accepted; review if licensing or distribution changes

Runtime and application images containing Obsidian Headless are kept private under the operator-confirmed packaging assumption recorded in the design work. Release automation must not publish these artifacts publicly. This constrains distribution and release infrastructure; revisit it if package terms, packaging, or intended distribution changes.

See [Private Service Deployment](../../specs/007-private-deployment/spec.md).
